## 🛠️ Development Setup

### Prerequisites
- Node.js 16+ (frontend)
- Java 17+ (backend)
- MySQL 8+ (database)
- Docker & Docker Compose (optional, recommended)

### Quick Start

**Backend**:
```bash
cd backend
mvn clean install
mvn spring-boot:run  # Runs on http://localhost:8080
```

**Frontend**:
```bash
cd frontend
npm install
npm start  # Runs on http://localhost:3000
```

**Database**:
```bash
docker-compose up -d  # Starts MySQL with database
# Or manually execute database/schema.sql
```

## 🔌 API Overview

### Authentication Endpoints
```
POST /auth/register       - Register new user
POST /auth/login          - User login
POST /auth/validate       - Validate token
POST /auth/refresh        - Refresh token
```

### Resource Endpoints
```
GET    /recipes           - List recipes (paginated)
POST   /recipes           - Create recipe
GET    /recipes/:id       - Get recipe detail
PUT    /recipes/:id       - Update recipe
DELETE /recipes/:id       - Delete recipe
GET    /recipes/search    - Search recipes
GET    /recipes/random    - Get random recipe

GET    /cuisines          - List cuisines
GET    /ingredients       - List ingredients

GET    /shopping-lists    - List shopping lists
POST   /shopping-lists    - Create list
PUT    /shopping-lists/:id/items - Manage items
DELETE /shopping-lists/:id - Delete list
```

**Total**: 40+ endpoints

## 💾 Database Schema

### Entity Models
1. **User** - User accounts with authentication
2. **Cuisine** - Recipe categories by cuisine
3. **Ingredient** - Food ingredients database
4. **Unit** - Measurement units (cup, tbsp, etc.)
5. **Recipe** - Recipe information
6. **RecipeIngredient** - Recipe ingredients with quantities
7. **ShoppingList** - User shopping lists
8. **ShoppingListItem** - Items in shopping lists

### Relationships
- User → Recipe (1:N)
- User → ShoppingList (1:N)
- Cuisine → Recipe (1:N)
- Recipe → RecipeIngredient (1:N)
- Ingredient → RecipeIngredient (1:N)
- Unit → RecipeIngredient (1:N)
- ShoppingList → ShoppingListItem (1:N)
- Ingredient → ShoppingListItem (1:N)
